Напиши полноценный Python-скрипт для Windows и macOS, который генерирует чеки или другие документы из HTML-шаблонов и данных CSV.

### Основная задача

Программа должна позволять пользователю быстро выбрать:

1. Какой HTML-шаблон использовать.
2. Какой CSV-файл использовать как источник данных.
3. Какую конкретную запись из CSV напечатать.
4. Нужно ли создать HTML, PDF или оба файла.

### Работа с файлами

HTML-шаблоны и CSV-файлы могут находиться в разных директориях.

Не привязывай программу к одному конкретному имени файла.

При запуске программа должна:

* просканировать заданные директории;
* найти доступные `.html` и `.csv` файлы;
* вывести найденные HTML-шаблоны списком;
* вывести найденные CSV-файлы списком;
* позволить выбрать нужный файл по номеру;
* после выбора CSV прочитать его содержимое;
* показать пользователю доступные записи;
* позволить выбрать конкретную запись по номеру.

Предусмотри возможность указать несколько директорий для поиска файлов.

Например:

```text
/templates
/data
/data/clients
/data/orders
/receipts
```

Поиск файлов должен выполняться также во вложенных папках.

### CSV

Используй стандартный модуль `csv`.

CSV содержит заголовки колонок.

Например:

```csv
id,name,product,quantity,price,total
1001,Иван Иванов,Товар 1,2,1500,3000
1002,Пётр Петров,Товар 2,1,2500,2500
```

После выбора CSV программа должна вывести записи примерно так:

```text
Выберите запись:

1. ID: 1001 | Иван Иванов | Товар 1 | 3000
2. ID: 1002 | Пётр Петров | Товар 2 | 2500

Введите номер:
```

Не привязывай отображение списка только к этим названиям колонок. Если структура CSV отличается, программа должна продолжать работать.

### HTML-шаблон

HTML-шаблон содержит плейсхолдеры, соответствующие названиям колонок CSV.

Например:

```html
<p>Номер чека: {{id}}</p>
<p>Клиент: {{name}}</p>
<p>Товар: {{product}}</p>
<p>Количество: {{quantity}}</p>
<p>Цена: {{price}}</p>
<p>Итого: {{total}}</p>
```

Для выбранной записи программа должна заменить плейсхолдеры вида:

```text
{{column_name}}
```

на соответствующие значения из CSV.

Для подстановки данных не используй Jinja2 или другие шаблонизаторы — реализуй простую замену средствами Python.

Неизвестные плейсхолдеры должны либо оставаться без изменения, либо программа должна вывести понятное предупреждение о том, для какого поля отсутствуют данные.

Значения из CSV перед вставкой должны безопасно экранироваться для HTML.

### Выбор шаблона

Если найдено несколько HTML-шаблонов, выводи их примерно так:

```text
Доступные шаблоны:

1. receipt.html
2. invoice.html
3. delivery_note.html

Выберите шаблон:
```

Показывай не только имя файла, но при необходимости и его директорию, чтобы можно было различать файлы с одинаковыми именами.

### Выбор CSV

Аналогично:

```text
Доступные файлы данных:

1. data/orders/september.csv
2. data/clients/client_001.csv
3. archive/2026/orders.csv

Выберите файл:
```

### Генерация HTML

После выбора шаблона и конкретной записи CSV:

1. Подставь значения в HTML.
2. Создай итоговый HTML-файл.
3. Сохрани его в папку:

```text
/output
```

Если папки нет — создай её автоматически.

Имя итогового файла формируй безопасно, например:

```text
receipt_1001.html
```

Не допускай недопустимых для Windows/macOS символов в имени файла.

### Генерация PDF

Добавь возможность преобразования итогового HTML в PDF.

Для PDF используй библиотеку:

```python
from weasyprint import HTML
```

Все остальные части программы по возможности должны использовать стандартную библиотеку Python.

Учти, что WeasyPrint — внешняя зависимость и должна быть отдельно установлена пользователем.

Каждая выбранная запись должна создавать отдельный PDF:

```text
/output/receipt_1001.pdf
```

### Кириллица

PDF должен корректно отображать русский текст.

Используй CSS со шрифтом:

* Roboto;
* или Liberation Sans.

Предусмотри fallback:

```css
font-family: "Roboto", "Liberation Sans", Arial, sans-serif;
```

Если используется локальный файл шрифта, подключи его через `@font-face`.

Не привязывай путь к шрифту только к Windows — решение должно работать также на macOS.

### Таблицы

Добавь CSS, чтобы таблицы хорошо выглядели в PDF.

Требования:

* аккуратные границы;
* `border-collapse: collapse`;
* внутренние отступы в ячейках;
* текст по центру;
* корректный перенос длинных строк;
* длинный текст не должен выходить за пределы страницы;
* ширина таблицы не должна выходить за ширину PDF.

Используй примерно такие свойства:

```css
table {
    width: 100%;
    border-collapse: collapse;
    table-layout: fixed;
}

th,
td {
    border: 1px solid #444;
    padding: 6px;
    text-align: center;
    vertical-align: middle;
    overflow-wrap: anywhere;
    word-wrap: break-word;
    white-space: normal;
}
```

### Открытие PDF

После создания PDF предложи автоматически открыть его в системной программе просмотра PDF.

Решение должно работать и на Windows, и на macOS.

Используй стандартные средства Python/операционной системы:

* Windows — `os.startfile()`;
* macOS — команда `open` через `subprocess`.

Не используй жёстко заданный путь к конкретному браузеру или PDF-программе.

Если открыть файл автоматически не удалось, программа не должна аварийно завершаться — выведи путь к созданному PDF.

### Режим работы

Сделай удобное консольное меню примерно такого вида:

```text
=================================
       ГЕНЕРАТОР ЧЕКОВ
=================================

Найдено шаблонов: 3
Найдено CSV-файлов: 5

1. Создать один чек
2. Создать PDF для всех записей CSV
3. Обновить список файлов
0. Выход
```

При выборе:

```text
1. Создать один чек
```

последовательность должна быть:

```text
Выберите HTML-шаблон
        ↓
Выберите CSV-файл
        ↓
Выберите конкретную запись
        ↓
Показать краткую информацию о выбранной записи
        ↓
Создать HTML
        ↓
Создать PDF
        ↓
Открыть PDF
```

В режиме массовой генерации программа должна создать отдельный PDF для каждой строки выбранного CSV.


### Обработка ошибок

Добавь понятную обработку ситуаций:

* HTML-шаблоны не найдены;
* CSV-файлы не найдены;
* CSV пустой;
* отсутствует строка заголовков;
* неправильный номер пункта меню;
* ошибка чтения файла;
* несовпадение плейсхолдеров и колонок;
* ошибка создания HTML;
* ошибка WeasyPrint;
* отсутствует WeasyPrint;
* не найден необходимый шрифт;
* ошибка открытия PDF.

Программа не должна завершаться с непонятным traceback при обычных пользовательских ошибках.
